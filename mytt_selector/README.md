# MYTT 选股器（自研，不依赖通达信 App）

把通达信的 **MYTT 指标公式**（万手单 + 寻龙诀4号）翻译成 Python，
用免费行情数据（akshare）自己选股，完全脱离通达信 App。

## 它选什么股

最终信号 = **万手单 AND 寻龙诀4号**（两个策略同一天都满足才出信号）。
原公式来自你提供的通达信源码，本仓库逐条翻译并复现。

## 项目结构

```
mytt_selector/
├── talc.py         通达信函数库的 Python 翻译(MA/REF/HHV/LLV/BARSLAST/FILTER/COUNT/CROSS/DMA)
├── mytt.py         万手单 + 寻龙诀4号 的完整计算
├── data.py         行情获取 + 磁盘缓存(当天数据只抓一次)
├── selector.py     每天收盘后快速选股(用当日快照预筛)
├── select_date.py  指定历史日期选股(用涨停池, 快)
├── scan_date.py    指定历史日期全市场扫描(慢, 备用)
├── run.py          日常选股入口
├── config.py       参数配置(复权方式/涨幅阈值等)
└── data/           缓存与结果输出目录
```

## 环境准备（只需一次）

需要电脑上装好 **Python 3.9+**。然后在 `mytt_selector` 目录下执行：

```bash
cd mytt_selector
pip3 install -r requirements.txt
```

## 用法

### 1) 每天收盘后选股（推荐）
```bash
python3 run.py
```
自动取全市场当日行情 → 预筛候选 → 逐只算信号 → 打印并保存 CSV。
**建议交易日 16:00 后运行**（此时当日收盘数据已更新）。
结果输出到 `data/mytt_result*.csv`。

### 2) 回溯某一天（如 9月23号）
```bash
python3 select_date.py 2026-09-23
```
用当天"涨停股池"做候选，快速复现那一日的选股记录。
结果输出到 `data/select_2026-09-23*.csv`。

## 结果怎么看

每个结果 CSV 都有 3 份：
- `...csv`（综合命中：万手单 AND 寻龙诀4号）
- `..._万手单.csv`（万手单单独命中）
- `..._寻龙诀4号.csv`（寻龙诀4号单独命中）

字段说明：`code` 代码、`name` 名称、`date` 信号日期、`close` 收盘价、
`chg_pct` 当日涨幅%、`sig_wanshou`/`sig_xlj4`/`signal` 三个布尔信号、
`WSD_25` 万手单内部形态条件、`XLJ4_7` 距上次寻龙诀信号的周期数。

## 常见问题

- **为什么综合命中很少？** 因为要两个策略同日同时满足，属于非常严格的形态，多数日子确实只有 0~2 只，甚至 0 只。这是公式本身的性质，不是 bug。
- **数据源**：免费 akshare（新浪/东财）。免费源偶尔会限流或断连，程序已做重试 + 本地缓存，重跑会很快。
- **复权**：默认前复权(qfq)，与多数人看通达信图表一致。可在 `config.py` 的 `ADJUST` 改成 `''`(不复权) 或 `hfq`(后复权)。
- **DYNAINFO(7) 现价**：原公式用盘中实时价，本工具按你的选择用**当日收盘价**替代，因此适合收盘后选股。
